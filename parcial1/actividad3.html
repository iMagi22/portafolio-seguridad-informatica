1. Flujo del Paquete en Netfilter

Cuando un paquete entra al sistema, primero pasa por una tabla PREROUTING, después por una tabla de INPUT o FORWARD, y finalmente se ejecuta una POSTROUTING.

2. Relación de Tablas y Propósitos

Tabla Propósito Principal Ejemplo de uso
FILTER Filtrado de paquetes (Aceptar/Denegar) Cerrar puerto 22
NAT Traducción de direcciones de red Redirección de puertos
MANGLE Modificación de cabeceras de paquetes Cambiar el TTL
RAW Configuración de exenciones de seguimiento NOTRACK

3. Anatomía y Análisis de Comandos

Comando base: iptables -A INPUT -p tcp -m multiport --dports 80,443 -j ACCEPT

Descripción: Permite el tráfico entrante para los puertos web estándar (HTTP y HTTPS).

Análisis de Regla Compleja:

iptables -A INPUT -i eth0 -p tcp -m multiport --dports 22,80,443 -m state --state NEW,ESTABLISHED -j ACCEPT

¿Qué hace esta regla?
Habilita un servidor web de forma segura. Permite ver las páginas web (puertos 80 y 443) y la administración remota (puerto 22 para SSH) a través de la interfaz eth0, siempre que sea tráfico TCP y el estado de la conexión sea nueva o ya establecida.

4. Traducción de Políticas a Comandos

  • Permitir SSH solo desde una IP específica:
    iptables -A INPUT -p tcp -s 192.168.1.50 --dport 22 -j ACCEPT
  • Permitir tráfico entrante a puertos 80 y 443 solo si la conexión es establecida:
    iptables -A INPUT -p tcp -m multiport --dports 80,443 -m state --state ESTABLISHED,RELATED -j ACCEPT
  • Denegar todo el tráfico entrante (Política restrictiva):
    iptables -P INPUT DROP
