Configuración de Políticas de Filtrado

A continuación se detallan las reglas implementadas para asegurar la infraestructura de red mediante el uso de iptables, estableciendo un perímetro de seguridad controlado.

1. Establecer una política restrictiva (Lista Blanca):

iptables -P FORWARD DROP
iptables -P INPUT DROP

// Se deniega todo tráfico por defecto para asegurar que solo lo explícitamente permitido pase.

2. Tráfico de conexiones ya establecidas:

iptables -A OUTPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

// Permite que las respuestas a peticiones legítimas salgan del sistema.

3. Servicio DNS (Resolución de nombres):

iptables -A OUTPUT -p tcp --dport 53 -s 192.1.2.0/24 -j ACCEPT

// Acepta tráfico DNS saliente desde la red local para navegar por IP.

4. Servidor de Correo (SMTP):

iptables -A INPUT -p tcp --dport 25 -d 192.1.2.10 -j ACCEPT
iptables -A OUTPUT -p tcp --dport 25 -s 192.1.2.10 -j ACCEPT

// Se permite el intercambio de correos (entrada y salida) específicamente para el servidor 192.1.2.10.

5. Servidor Web (HTTP):

iptables -A INPUT -p tcp --dport 80 -d 192.1.2.11 -j ACCEPT

// Permite conexiones externas al servidor web institucional.

6. Navegación de Usuarios Locales:

iptables -A OUTPUT -p tcp --dport 80 -s 192.1.2.0/24 -j ACCEPT

// Los usuarios de la red local pueden realizar peticiones HTTP hacia Internet.

Resumen de Seguridad

Esta configuración aplica el Principio de Mínimo Privilegio, cerrando todas las comunicaciones innecesarias y abriendo exclusivamente los puertos 53 (DNS), 25 (SMTP) y 80 (HTTP) para las IPs correspondientes.

7. Reflexión Técnica

La implementación de una "Lista Blanca" o política restrictiva por defecto es el estándar de oro en firewalls corporativos. Aunque es más difícil de configurar inicialmente, reduce drásticamente la superficie de ataque. Vincular esto con el "Principio de Mínimo Privilegio" me hace entender que en seguridad informática, todo lo que no está explícitamente permitido, debe ser prohibido para evitar exfiltración de datos por puertos no controlados.
