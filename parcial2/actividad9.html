RESUMEN EJECUTIVO
Se realizó una evaluación de seguridad ofensiva (Penetration Test) sobre la máquina vulnerable My File Server: 1 de Armour Infosec, con IP 192.168.0.8, bajo el estándar PTES en modalidad Black Box — sin credenciales previas.

El vector inicial fue un archivo readme.txt con credenciales en texto plano accesible vía HTTP. La cadena: credenciales → FTP autenticado → inyección llave SSH → shell smbuser → Dirty COW (CVE-2016-5195) → root. Compromiso total en 4 pasos con herramientas públicas.

ANÁLISIS DE IMPACTO — MODELO CIA
C
Confidencialidad
IMPACTO: CRÍTICO
Credenciales expuestas en HTTP público. Con acceso root se puede leer /etc/shadow, datos de usuarios, archivos SMB y toda información almacenada. Exposición total.
I
Integridad
IMPACTO: CRÍTICO
Root permite modificar cualquier binario, log o configuración. Dirty COW sobreescribió /usr/bin/passwd. SMB smbdata con R/W sin auth disponible para cualquier actor de red.
A
Disponibilidad
IMPACTO: ALTO
Con acceso root es posible detener servicios, eliminar archivos críticos, instalar rootkits/backdoors o apagar el servidor. No se realizaron acciones destructivas durante la evaluación.

RECOMENDACIONES TÉCNICAS
CRÍTICOREC-01
Eliminar credenciales expuestas en recursos web
Eliminar readme.txt inmediatamente. Política de contraseñas con hashing seguro (bcrypt/argon2). Auditar servidor web.
CRÍTICOREC-02
Actualizar el kernel del sistema operativo
Actualizar a mínimo 3.10.0-514.6.2.el7 (parche CVE-2016-5195). Ejecutar yum update kernel. Proceso de parches periódico documentado.
ALTOREC-03
Deshabilitar acceso FTP anónimo
Establecer anonymous_enable=NO en /etc/vsftpd/vsftpd.conf. Si no es necesario, deshabilitar. Migrar a SFTP o FTPS con certificados.
ALTOREC-04
Restringir permisos del recurso SMB 'smbdata'
Agregar guest ok = no y valid users = @smbusers en /etc/samba/smb.conf. Habilitar registro de accesos.
ALTOREC-05
Restringir escritura en directorios home vía FTP
Implementar chroot_local_user=YES en vsftpd. Revocar inmediatamente las llaves SSH inyectadas del archivo authorized_keys de smbuser.
MEDIOREC-06
Hardening Apache — TRACE, Indexing, Headers
Agregar TraceEnable Off, Options -Indexes, ServerTokens Prod y cabecera X-Frame-Options en la configuración de Apache.
MEDIOREC-07
Monitoreo y detección de intrusos
IDS/IPS (Snort/Suricata), SIEM centralizado y fail2ban en FTP/SSH/HTTP. Pentesting trimestral documentado.

CONCLUSIÓN Y REFLEXIÓN TÉCNICA

// CONCLUSIÓN EJECUTIVA

La evaluación sobre My File Server: 1 demostró un nivel de exposición CRÍTICO. Con siete vulnerabilidades documentadas, fue posible pasar de cero conocimiento (black box) a compromiso total como root en el transcurso de una sesión de laboratorio. El vector inicial fue un archivo de texto con credenciales en claro accesible por HTTP — un error de administración básico con consecuencias devastadoras.

La cadena fue completamente lineal y previsible: readme.txt → credenciales → FTP → inyección SSH → Dirty COW → root. Ningún paso requirió técnicas avanzadas. Todas las herramientas utilizadas son públicas y documentadas desde hace años, lo que hace este escenario aún más grave. Nivel de riesgo global: CRÍTICO (CVSS 9.8).

// REFLEXIÓN TÉCNICA — APRENDIZAJES

Esta actividad solidificó en la práctica lo estudiado en CNO V: la seguridad es un sistema de capas, no una medida aislada. Un único archivo mal administrado desencadenó una cadena que terminó en compromiso total del servidor.

El modelo CIA dejó de ser abstracto: las tres dimensiones resultaron comprometidas con consecuencias medibles, desde exfiltración de /etc/shadow hasta posible destrucción del sistema.

Dirty COW (CVE-2016-5195) es un recordatorio de que parchear el kernel no es opcional: un exploit público de 2016, compilado con gcc estándar, obtuvo root en segundos. La gestión de parches es una línea de defensa crítica que este servidor tenía completamente descuidada.

La metodología PTES demostró ser eficaz como marco estructurado: las fases en orden garantizaron cobertura sistemática de todos los vectores, maximizando la calidad del análisis en tiempo limitado de laboratorio.
