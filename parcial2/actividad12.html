Fundamentos Técnicos

¿Qué es un Keylogger? Software o hardware diseñado para registrar y almacenar las pulsaciones de un teclado. En ciberseguridad se clasifican como spyware; su estudio es fundamental para entender vectores de ataque y desarrollar contramedidas de defensa.
¿Qué es la librería Pynput? Biblioteca de Python que permite monitorizar y controlar dispositivos de entrada (teclado y ratón). El submódulo pynput.keyboard proporciona clases como Key y Listener para capturar eventos de forma asíncrona.
¿Cómo funciona el Listener? Crea un hilo (thread) dedicado que intercepta eventos del sistema operativo a bajo nivel. Utiliza callbacks (on_press y on_release) para ejecutar código cuando ocurre una pulsación o liberación de tecla sin bloquear el flujo principal del programa.
¿Por qué se usa try/except AttributeError? Las teclas especiales (Shift, Ctrl, Esc, etc.) no tienen atributo .char, solo Key. El bloque try/except diferencia entre caracteres alfanuméricos y teclas especiales para mostrar la información correcta sin que el programa falle.

Análisis de Componentes del Código

Componente Función Evento
Listener Hilo que escucha eventos del teclado en segundo plano Background process
on_press(key) Callback ejecutado al presionar una tecla Key pressed
on_release(key) Callback ejecutado al soltar una tecla Key released
key.char Retorna el carácter alfanumérico presionado Alphanumeric key
key == Key.esc Condición de salida que detiene el listener Stop condition
listener.join() Mantiene el hilo activo hasta que termine Thread blocking

Estructura del Script

# Importación de clases necesarias de pynput from pynput.keyboard import Key, Listener # Callback: se ejecuta cada vez que se presiona una tecla def on_press(key): try: print(f'Alphanumeric key pressed: {key.char}') except AttributeError: print(f'Special key pressed: {key}') # Callback: se ejecuta cada vez que se suelta una tecla def on_release(key): print(f'Key released: {key}') if key == Key.esc: # Detener el listener al presionar ESC return False # Inicialización del listener con los callbacks definidos with Listener(on_press=on_press, on_release=on_release) as listener: listener.join()

Reflexión Técnica

El desarrollo de este keylogger educativo evidencia lo sencillo que resulta capturar información de entrada mediante librerías de Python de alto nivel. Aunque Pynput tiene usos legítimos (automatización, accesibilidad, pentesting autorizado), su facilidad de implementación subraya por qué los atacantes recurren a técnicas similares para robar credenciales y datos sensibles.

La detección de este tipo de malware requiere soluciones de Endpoint Detection and Response (EDR), monitoreo de procesos sospechosos y educación del usuario. Comprender el funcionamiento interno de un keylogger es el primer paso para diseñar arquitecturas defensivas y políticas de seguridad efectivas.
